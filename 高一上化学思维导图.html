🧩 第一章 物质及其变化

分类 · 胶体 · 电解质 · 离子反应 · 氧化还原

👩‍🏫
初中你已经认识了酸、碱、盐这些“同学”。高一第一章要学三件新本事：给物质分组（分类）、看清溶液里真正“干活”的是哪些离子（离子反应），以及看出谁把电子交出去、谁把电子抢过来（氧化还原）。这三件本事贯穿整个高中化学——第二、三章学钠、氯、铁，每个方程式都要用它们来“读”。

🧱 初中地基：先确认这些会了

  • 物质分类纯净物/混合物、单质/化合物、氧化物·酸·碱·盐初中①物质的构成·分类树 ↗
  • 化合价化合价口诀、根据化学式求化合价（氧化还原的基础）初中②化学用语 ↗
  • 复分解反应溶解性口诀、复分解条件：沉淀/气体/水（离子反应的基础）初中③酸碱盐 ↗
  • 反应类型化合、分解、置换、复分解初中④化学反应 ↗

📌 物质的分类：树状 + 交叉

  • 树状分类法：物质 → 纯净物（单质、化合物）/ 混合物；化合物 → 酸、碱、盐、氧化物
  • 交叉分类法：同一物质换个标准换个“组”——Na2CO3 既是钠盐，又是碳酸盐，还是可溶性盐、正盐
  • 酸性氧化物：能与碱反应只生成盐和水，如 CO2、SO2；碱性氧化物：能与酸反应只生成盐和水，如 CaO、Na2O、CuO
  • 同素异形体：同种元素组成的不同单质，如 O2 与 O3，金刚石、石墨与 C60

⚠️ 非金属氧化物不一定是酸性氧化物（CO 不是）；金属氧化物不一定是碱性氧化物（Na2O2 不是，Mn2O7 还是酸性氧化物）。

⚗️ 物质的转化：一条“金属线”和一条“非金属线”

金属 → 碱性氧化物 → 碱 → 盐；非金属 → 酸性氧化物 → 酸 → 盐

🔬 分散系与胶体：按“粒子大小”排座位

溶液< 1 nm均一稳定，透明
胶体1 ~ 100 nm较稳定，有丁达尔效应
浊液> 100 nm不稳定，静置分层/沉淀

分散系的本质区别：分散质粒子直径大小（不是丁达尔效应！丁达尔效应只是鉴别方法）

  • Fe(OH)₃ 胶体的制备：向沸腾的蒸馏水中逐滴加入 5~6 滴 FeCl3 饱和溶液，继续煮沸至液体呈红褐色，停止加热
FeCl3 + 3H2O△Fe(OH)3(胶体) + 3HCl写“(胶体)”，不标↓
  • 胶体粒子能透过滤纸，不能透过半透膜
  • 鉴别溶液和胶体：用丁达尔效应

🏠 生活里的胶体

  • 🚗 雾天车灯照出光柱、林间的光束：丁达尔效应
  • 🥛 豆浆“点卤”成豆腐、江河入海口形成三角洲：胶体聚沉
  • 💧 明矾净水：生成 Al(OH)₃ 胶体吸附杂质
  • 🩸 血液也是胶体，透析就是利用半透膜

📌 电解质与电离

  • 电解质：在水溶液里或熔融状态下能导电的化合物——酸、碱、盐、金属氧化物、水
  • 非电解质：两种情况下都不导电的化合物——蔗糖、酒精、CO2、NH3
  • 单质、混合物既不是电解质也不是非电解质：Cu、盐酸、NaCl 溶液都不是
  • NaCl 固体不导电（离子不能自由移动）；溶于水或熔融后电离出自由移动的离子才导电
  • 酸：电离出的阳离子全部是 H+；碱：电离出的阴离子全部是 OH-

📌 离子方程式：写、拆、删、查

✍️ 写写出化学方程式✂️ 拆易溶、易电离的拆成离子🗑️ 删删去两边相同的离子🔍 查原子守恒 + 电荷守恒
✂️ 要拆强酸 HCl、H2SO4、HNO3；强碱 NaOH、KOH、Ba(OH)2、澄清石灰水中的 Ca(OH)2；可溶性盐
🚫 不拆单质、氧化物、气体、沉淀、水；弱酸（H2CO3、CH3COOH、HClO）、弱碱（NH3·H2O）；弱酸的酸式酸根 HCO3-

离子反应发生的条件：生成沉淀、气体或水（难电离物质），本质是溶液中某些离子浓度减小。

📌 离子共存：会“打架”的不能待在一起

  • 生成沉淀：Ba2+ 与 SO42-/CO32-；Ag+ 与 Cl-；Ca2+ 与 CO32-；Cu2+、Fe3+、Mg2+ 与 OH-
  • 生成气体：H+ 与 CO32-、HCO3-
  • 生成水/弱电解质：H+ 与 OH-；OH- 与 HCO3-；H+ 与 CH3COO-、ClO-
  • 题目隐含条件：“无色”“酸性”“碱性”——详见 易错与解题模型

📌 氧化还原反应：电子的“交接仪式”

  • 特征：元素化合价有升降；本质：电子转移（得失或偏移）
  • 还原剂：失电子 → 化合价升高 → 被氧化 → 发生氧化反应 → 得到氧化产物
  • 氧化剂：得电子 → 化合价降低 → 被还原 → 发生还原反应 → 得到还原产物
  • 强弱规律：氧化性 氧化剂 > 氧化产物；还原性 还原剂 > 还原产物
  • 常见氧化剂：O2、Cl2、浓 H2SO4、HNO3、KMnO4、FeCl3；常见还原剂：活泼金属、C、H2、CO

升失氧，降得还

（化合价升高、失电子、被氧化；降低、得电子、被还原）

若说剂，正相反

🔬 双线桥与单线桥

① 双线桥（同种元素“从左连到右”，标得失）

② 单线桥（从还原剂失电子的元素指向氧化剂得电子的元素，只标总数，不写得失）

CuO + H2△Cu + H2O

得失电子数相等：Cu 得 2e⁻ = 2 个 H 共失 2×e⁻。这就是后面配平用的“得失电子守恒”。

🔬 氧化还原与四大基本反应类型

  • 置换反应一定是氧化还原反应
  • 复分解反应一定不是
  • 有单质参加的化合反应、有单质生成的分解反应是

⚠️ 易错点

  • ✗ NaCl 溶液能导电，所以 NaCl 溶液是电解质✓ 溶液是混合物；NaCl 才是电解质
  • ✗ CO₂ 溶于水能导电，所以 CO₂ 是电解质✓ 导电的是 H₂CO₃ 电离的离子，CO₂ 是非电解质
  • ✗ 碳酸钙与盐酸：CO₃²⁻ + 2H⁺ = H₂O + CO₂↑✓ CaCO₃ 难溶不拆：CaCO₃ + 2H⁺ = Ca²⁺ + H₂O + CO₂↑
  • ✗ 胶体与溶液的本质区别是丁达尔效应✓ 本质区别是分散质粒子直径大小
  • ✗ 氧化剂发生氧化反应✓ 氧化剂被还原，发生还原反应
  • ✗ 有单质参加的反应一定是氧化还原反应✓ O₂ 转化为 O₃ 不是氧化还原反应

🌊 第二章 海水中的重要元素——钠和氯

钠及其化合物 · 氯及其化合物 · 物质的量

👩‍🏫
海水里最多的盐是 NaCl。把它“拆开”，就得到两个性格极端的元素：钠是个急脾气，碰到水就“浮熔游响红”；氯是个霸道的黄绿色气体，能漂白、能杀菌。本章后半段学一个新工具——物质的量（mol），它像化学里的“打”或“箱”，让我们能数清看不见的粒子。它是整个高中化学计算的地基，务必学扎实。

🔬 物质的量：以 n 为中心的换算

  • 阿伏加德罗常数 NA ≈ 6.02×1023 mol−1：1 mol 任何粒子含 NA 个
  • 摩尔质量 M：单位 g/mol，数值等于相对分子（原子）质量，如 M(H2O) = 18 g/mol
  • 气体摩尔体积 Vm：标准状况（0 ℃、101 kPa）下约为 22.4 L/mol，只适用于气体
  • 物质的量浓度 c = n / V(溶液)，单位 mol/L；稀释：c浓V浓 = c稀V稀
  • 同温同压下，相同体积的任何气体含有相同数目的分子（阿伏加德罗定律）

✏️ 算一算：4.4 g CO₂

n = m / M = 4.4 g ÷ 44 g/mol = 0.1 mol

N = n·NA = 0.1 × 6.02×1023 = 6.02×1022 个分子，含 O 原子 0.2 mol

标况下 V = n·Vm = 0.1 × 22.4 = 2.24 L

溶液：把 5.85 g NaCl 配成 100 mL 溶液，c = 0.1 mol ÷ 0.1 L = 1.00 mol/L

质量分数 ↔ 物质的量浓度：c = 1000ρw / M（ρ 单位 g/cm³）

🔬 配制一定物质的量浓度的溶液

1🧮计算m = c·V·M
2⚖️称量天平/量筒
3🥣溶解烧杯中溶解，冷却至室温
4🫗转移玻璃棒引流
5💧洗涤洗烧杯和玻璃棒2~3次，洗液也转入
6🎯定容离刻度线1~2 cm改用胶头滴管

🔩 第三章 铁 金属材料

铁及其化合物 · Fe²⁺/Fe³⁺ · 铝的两性 · 合金 · 方程式计算

👩‍🏫
铁是“会变脸”的元素：0 价的铁单质、+2 价的亚铁（浅绿色）、+3 价的铁（棕黄色），三者之间可以互相转化，这就是著名的“铁三角”。理解铁三角的钥匙就是第一章学的氧化还原：往高价走需要氧化剂，往低价走需要还原剂。本章还认识一个“两面派”——铝，它既能和酸反应又能和碱反应。

📌 金属材料：合金

  • 合金：两种或以上金属（或金属与非金属）熔合而成，具有金属特性
  • 合金硬度一般大于成分金属，熔点一般低于成分金属
  • 铁合金：生铁含碳 2%~4.3%，钢含碳 0.03%~2%；不锈钢中加入 Cr、Ni
  • 铝合金：硬铝（含 Cu、Mg、Mn、Si）密度小、强度高，用于飞机、高铁
  • 新型合金：储氢合金、钛合金、形状记忆合金

🔭 第四章 物质结构 元素周期律

原子结构 · 核素 · 周期表 · 周期律 · 化学键

👩‍🏫
为什么钠急脾气、氯霸道、氖“佛系”？答案藏在原子的最外层电子里。门捷列夫把元素排成一张表，结果发现性质会“周期性”重复——就像一周七天循环。本章就是把前三章零散的元素知识，用“结构决定性质”这根线串起来。

📌 原子结构与核外电子排布

AZX　质量数 A = 质子数 Z + 中子数 N

  • 如 3717Cl：质子数 17，中子数 37 − 17 = 20，电子数 17
  • 核外电子排布：由内向外、能量由低到高分层排布
  • 每层最多容纳 2n² 个电子；最外层不超过 8 个（K 层为最外层时不超过 2 个）；次外层不超过 18 个
  • 阳离子：电子数 = 质子数 − 电荷数；阴离子：电子数 = 质子数 + 电荷数

📌 元素、核素、同位素

  • 元素：质子数相同的一类原子的总称
  • 核素：具有一定数目质子和中子的一种原子
  • 同位素：质子数相同而中子数不同的同一元素的不同核素互称同位素
  • 氢的三种核素：11H 氕、21H 氘（D）、31H 氚（T）
  • 126C 是相对原子质量的标准；146C 用于考古断代；23592U 是核燃料
  • 同位素化学性质几乎相同，物理性质有差异

分清“四同”：同位素（原子）、同素异形体（单质，如 O2 与 O3）。

🔬 元素周期表与递变规律

  • 7 个周期（1、2、3 短周期，元素数 2、8、8）；18 个纵列 16 个族：7 个主族、7 个副族、第 Ⅷ 族、0 族
  • 周期序数 = 电子层数；主族序数 = 最外层电子数 = 最高正价（O、F 除外）
  • 非金属：最高正价 + |最低负价| = 8

⚗️ 碱金属：越往下越“急”

  • Li、Na、K、Rb、Cs：最外层都是 1 个电子，易失电子，化学性质相似
  • 从上到下：电子层数增多 → 原子半径增大 → 失电子能力增强 → 金属性增强，与水反应越来越剧烈
4Li + O2△2Li2O锂只生成 Li₂O
2Na + O2△Na2O2
2K + 2H2O2KOH + H2↑比钠更剧烈，轻微爆炸

⚗️ 卤族元素：越往下越“温和”

  • F、Cl、Br、I：最外层 7 个电子，易得电子
  • 单质颜色加深：F2 淡黄绿色 → Cl2 黄绿色 → Br2 深红棕色液体 → I2 紫黑色固体；熔沸点升高
  • 与 H2 化合越来越难，氢化物稳定性 HF > HCl > HBr > HI，非金属性减弱
Cl2 + 2KBr2KCl + Br2
Cl2 + 2KI2KCl + I2
Br2 + 2KI2KBr + I2
Cl2 + 2Br-2Cl- + Br2离子方程式

氧化性 Cl2 > Br2 > I2；淀粉遇 I2 变蓝。

  • 本质：元素性质随原子序数递增呈周期性变化，根本原因是核外电子排布的周期性变化
  • 金属性判断：与水/酸置换出氢的难易；最高价氧化物对应水化物的碱性强弱
  • 非金属性判断：与 H2 化合的难易及氢化物稳定性；最高价含氧酸的酸性强弱
  • 微粒半径：电子层多的半径大；电子层相同，核电荷数大的半径小——Na+ > Mg2+ > Al3+，O2- > F- > Na+

📌 化学键：原子之间的“胶水”

  • 离子键：阴、阳离子之间的静电作用——活泼金属与活泼非金属（NaCl、MgCl2），铵盐中也有
  • 共价键：原子间通过共用电子对形成——同种原子间为非极性键（Cl–Cl），不同原子间为极性键（H–Cl）
  • 离子化合物：含离子键（可能还含共价键，如 NaOH、Na2O2、NH4Cl）
  • 共价化合物：只含共价键（HCl、H2O、CO2）
  • 化学反应的本质：旧化学键断裂、新化学键形成

🔬 电子式：把最外层电子“画”出来

NaCl（离子化合物）离子：阴离子要加 [ ] 并标电荷
HCl（共价化合物）H–Cl，不加 [ ]、不标电荷
H₂OH–O–H
CO₂O=C=O（两对共用电子对 = 双键）
N₂N≡N（三对共用电子对 = 三键）

用电子式表示 NaCl 的形成过程（× 表示 Na 的电子，· 表示 Cl 的电子；弯箭头表示电子转移）

📌 分子间作用力与氢键

  • 分子间作用力（范德华力）比化学键弱得多，影响物质的熔点、沸点等物理性质
  • 组成和结构相似的分子，相对分子质量越大，分子间作用力越大，熔沸点越高：F2 < Cl2 < Br2 < I2
  • 氢键：存在于 H2O、NH3、HF 等分子之间，使它们熔沸点“反常”偏高（H2O 沸点高于 H2S）；冰的密度比水小也与氢键有关
  • 氢键不是化学键，属于一种较强的分子间作用

⚠️ 易错点

  • ✗ 同位素的化学性质不同✓ 同位素化学性质几乎相同，物理性质不同
  • ✗ H₂、D₂、T₂ 互为同位素✓ 同位素指原子；它们是同种单质（氢气）
  • ✗ 含有共价键的化合物一定是共价化合物✓ NaOH、Na₂O₂ 含共价键但是离子化合物
  • ✗ HCl 的电子式写成 H⁺[:Cl:]⁻✓ HCl 是共价化合物，H 与 Cl 共用一对电子
  • ✗ HF 比 HCl 沸点高，是因为 H–F 键更牢固✓ 沸点高是因为 HF 分子间有氢键；键能影响的是稳定性

🧠 易错与解题模型

离子共存 · 氧化还原配平 · NA 陷阱 · 配制误差

👩‍🏫
高一考试最爱“挖坑”的四个地方都在这里。每个模型都给出固定的思考步骤——像拿着一张检查清单，一项项打勾，就不会掉坑。做题时别急着选，先在草稿纸上把清单走一遍。

🧱 初中地基：先确认这些会了

  • 溶解性口诀哪些是沉淀（离子共存的第一关）初中③溶解性口诀 ↗
  • 化合价标价态是配平的第一步初中②化合价口诀 ↗
  • 量筒读数仰视、俯视的偏差（和容量瓶定容同理）初中⑤基本操作 ↗

点 ↗ 在新标签页打开《初中化学思维导图》对应分图；不熟就先回补，再往下看。

📌 模型① 离子共存：四看清单

  1. 一看颜色：题目说“无色”→ 排除 Cu2+（蓝）、Fe3+（棕黄）、Fe2+（浅绿）、MnO4-（紫红）
  2. 二看酸碱性：酸性溶液（含 H+）不能有 OH-、CO32-、HCO3-、ClO-；碱性溶液（含 OH-）不能有 H+、NH4+、Mg2+、Cu2+、Fe3+、Fe2+、Al3+、HCO3-
  3. 三看反应：能否生成沉淀、气体、水；能否发生氧化还原（Fe2+ 与 MnO4-/ClO-、H++NO3- 不共存）
  4. 四看特殊：HCO3- 遇酸遇碱都不能大量存在

例：在无色酸性溶液中能大量共存的是（　）

A. K+、Na+、Cl-、SO42-　B. Cu2+、Na+、Cl-、SO42-

C. Na+、K+、CO32-、Cl-　D. Na+、Ba2+、OH-、NO3-

B 有颜色 ✗；C 中 CO32- 遇 H+ ✗；D 中 OH- 遇 H+ ✗ → 选 A

📌 模型② 氧化还原配平：得失电子守恒

🏷️ 标价态标出变价元素📈 列变化每个原子升/降几价⚖️ 求相等最小公倍数使得失相等👀 配其余观察法配平，再查守恒

例1：MnO₂ + HCl(浓) → MnCl₂ + Cl₂ + H₂O

Mn：+4 → +2，得 2e⁻；Cl：−1 → 0，生成 1 个 Cl₂ 失 2×e⁻ → 得失已相等，MnO₂ 与 Cl₂ 都配 1

再看 Cl 原子：MnCl₂ 中 2 个 + Cl₂ 中 2 个 = 4 个 → 4HCl，H₂O 配 2

MnO2 + 4HCl(浓)△MnCl2 + Cl2↑ + 2H2O

4 个 HCl 中只有 2 个被氧化（作还原剂），另外 2 个起酸的作用。

例2：KMnO₄ + HCl(浓) → KCl + MnCl₂ + Cl₂ + H₂O

Mn：+7 → +2，得 5e⁻；生成 1 个 Cl₂ 失 2e⁻；最小公倍数 10 → 2KMnO₄、5Cl₂

Cl 原子：2KCl + 2MnCl₂ + 5Cl₂ 共 2 + 4 + 10 = 16 → 16HCl，H₂O 配 8

2KMnO4 + 16HCl(浓)2KCl + 2MnCl2 + 5Cl2↑ + 8H2O

计算题秒杀：氧化剂得电子总数 = 还原剂失电子总数

📋 模型③ NA 陷阱题：逐条“排雷”

  • ✗ 标准状况下，22.4 L H₂O 含 NA 个分子✓ 标况下水不是气体，不能用 22.4 L/mol（CCl₄、乙醇同理）
  • ✗ 常温常压下，22.4 L Cl₂ 含 NA 个分子✓ 不是标准状况，不能用 22.4 L/mol
  • ✗ 1 mol/L NaCl 溶液中含 NA 个 Na⁺✓ 没给溶液体积，无法计算
  • ✗ 1 mol Na₂O₂ 中含离子总数 4NA✓ Na₂O₂ 由 2Na⁺ 和 1 个 O₂²⁻ 构成，离子总数 3NA
  • ✗ 1 mol Na₂O₂ 与足量 CO₂ 反应转移 2NA 个电子✓ O 由 −1 价一半升一半降，转移 NA 个电子
  • ✗ 1 mol Fe 与足量 Cl₂ 反应转移 2NA 个电子✓ 生成 FeCl₃，转移 3NA 个电子
  • ✗ 1 mol 氦气含 2NA 个原子✓ 稀有气体是单原子分子，含 NA 个原子

✅ 不受状况影响的：质量、物质的量、粒子数——“18 g H₂O 在任何条件下都含 NA 个分子”是对的；32 g O₂ 与 O₃ 的混合物含 2NA 个 O 原子也对。1 mol Cl₂ 与足量 NaOH 反应转移 NA 个电子（歧化）。

🔬 模型④ 配制误差：盯住 c = n / V

操作影响结果
未洗涤烧杯和玻璃棒n 偏小偏低
转移时有液体洒出n 偏小偏低
称量时“左码右物”且使用了游码n 偏小偏低
定容时仰视刻度线V 偏大偏低
定容加水超过刻度线，用滴管吸出n 偏小偏低
摇匀后液面低于刻度线，再加水V 偏大偏低
定容时俯视刻度线V 偏小偏高
溶液未冷却至室温就转移、定容V 偏小偏高
砝码生锈n 偏大偏高
容量瓶未干燥，有少量蒸馏水无影响无影响

📌 模型⑤ 以物质的量为中心的计算

  • 无论题目给的是质量、体积、粒子数还是浓度，第一步都先换算成 n
  • 方程式中用系数比找 n 的关系，最后再换算成题目要的量
  • 多步反应找“关系式”：如 2Al ~ 3H2；MnO2 ~ Cl2
  • 守恒法：原子守恒、电荷守恒、得失电子守恒，能省掉大量计算
