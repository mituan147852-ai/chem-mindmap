🧩 第一章 物质及其变化

分类 · 胶体 · 电解质 · 离子反应 · 氧化还原

👩‍🏫

📌 物质的分类：树状 + 交叉

  • 树状分类法：物质 → 纯净物（单质、化合物）/ 混合物；化合物 → 酸、碱、盐、氧化物
  • 交叉分类法：同一物质换个标准换个“组”——Na2CO3 既是钠盐，又是碳酸盐，还是可溶性盐、正盐
  • 酸性氧化物：能与碱反应只生成盐和水，如 CO2、SO2；碱性氧化物：能与酸反应只生成盐和水，如 CaO、Na2O、CuO
  • 同素异形体：同种元素组成的不同单质，如 O2 与 O3，金刚石、石墨与 C60

⚠️ 非金属氧化物不一定是酸性氧化物（CO 不是）；金属氧化物不一定是碱性氧化物（Na2O2 不是，Mn2O7 还是酸性氧化物）。

💡 老师讲透分类就像给班里同学分组：按“成分”分（纯净物/混合物），按“元素种类”分（单质/化合物），按“性质”分（酸、碱、盐、氧化物）。标准不同，组就不同——这就是交叉分类。考试最常考的是“氧化物的分类”：能和碱反应只生成盐和水的是酸性氧化物，能和酸反应只生成盐和水的是碱性氧化物。

🔬 分散系与胶体：按“粒子大小”排座位

溶液< 1 nm均一稳定，透明
胶体1 ~ 100 nm较稳定，有丁达尔效应
浊液> 100 nm不稳定，静置分层/沉淀

分散系的本质区别：分散质粒子直径大小（不是丁达尔效应！丁达尔效应只是鉴别方法）

  • Fe(OH)₃ 胶体的制备：向沸腾的蒸馏水中逐滴加入 5~6 滴 FeCl3 饱和溶液，继续煮沸至液体呈红褐色，停止加热
FeCl3 + 3H2O△Fe(OH)3(胶体) + 3HCl写“(胶体)”，不标↓
  • 胶体粒子能透过滤纸，不能透过半透膜
  • 鉴别溶液和胶体：用丁达尔效应
💡 老师讲透三种分散系的本质区别只有一个：分散质粒子直径大小。丁达尔效应是现象（用来鉴别），不是本质区别。胶体“稳定”是因为胶粒带同种电荷互相排斥，所以加电解质、加热、加带相反电荷的胶体都能使它聚沉。
✏️ 例题下列说法正确的是（　）A. 溶液与胶体的本质区别是有无丁达尔效应　B. 用滤纸可以分离胶体和溶液　C. 向沸水中滴加 FeCl3 饱和溶液可制得 Fe(OH)₃ 胶体　D. 胶体是带电的
点我看解析
选 C。A：本质区别是粒子直径；B：胶粒能透过滤纸，要用半透膜（渗析）；D：胶粒带电，胶体整体呈电中性。
⚠️ 易错提醒制 Fe(OH)₃ 胶体时不能用 NaOH 溶液（得到的是沉淀），也不能长时间加热或搅拌（会聚沉）。

🏠 生活里的胶体

  • 🚗 雾天车灯照出光柱、林间的光束：丁达尔效应
  • 🥛 豆浆“点卤”成豆腐、江河入海口形成三角洲：胶体聚沉
  • 💧 明矾净水：生成 Al(OH)₃ 胶体吸附杂质
  • 🩸 血液也是胶体，透析就是利用半透膜
💡 老师讲透生活里的胶体现象都可以归到三个词：丁达尔效应（光路）、聚沉（点豆腐、三角洲、不同墨水混用堵笔）、吸附（明矾净水）。看到现象先想“粒子大小在 1~100 nm 吗”。

✏️ 例题“卤水点豆腐”和“江河入海口形成三角洲”的原理相同吗？
点我看解析
相同，都是胶体遇电解质发生聚沉：卤水中的 MgCl2 等使豆浆胶体聚沉，海水中的盐使河水中的泥沙胶体聚沉。

📌 电解质与电离

  • 电解质：在水溶液里或熔融状态下能导电的化合物——酸、碱、盐、金属氧化物、水
  • 非电解质：两种情况下都不导电的化合物——蔗糖、酒精、CO2、NH3
  • 单质、混合物既不是电解质也不是非电解质：Cu、盐酸、NaCl 溶液都不是
  • NaCl 固体不导电（离子不能自由移动）；溶于水或熔融后电离出自由移动的离子才导电
  • 酸：电离出的阳离子全部是 H+；碱：电离出的阴离子全部是 OH-
NaClNa+ + Cl-
H2SO42H+ + SO42-
Ba(OH)2Ba2+ + 2OH-
NaHSO4Na+ + H+ + SO42-在水溶液中
NaHCO3Na+ + HCO3-HCO₃⁻ 不拆
💡 老师讲透判断电解质两步走：① 是不是化合物？② 它自己在水溶液或熔融状态下能不能电离出离子？CO2 溶于水导电，是因为生成的 H2CO3 电离，CO2 自己是非电解质。写电离方程式时，强电解质用“=”，原子团不拆。
✏️ 例题写出 H2SO4、Ba(OH)₂、NaHSO4（水溶液中）、NaHCO3 的电离方程式。
点我看解析
H₂SO₄ = 2H⁺ + SO₄²⁻；Ba(OH)₂ = Ba²⁺ + 2OH⁻；NaHSO₄ = Na⁺ + H⁺ + SO₄²⁻；NaHCO₃ = Na⁺ + HCO₃⁻（HCO₃⁻ 不拆）。
⚠️ 易错提醒能导电的不一定是电解质（Cu、盐酸）；电解质不一定能导电（NaCl 固体）。

📌 离子方程式：写、拆、删、查

✍️ 写写出化学方程式✂️ 拆易溶、易电离的拆成离子🗑️ 删删去两边相同的离子🔍 查原子守恒 + 电荷守恒
✂️ 要拆强酸 HCl、H2SO4、HNO3；强碱 NaOH、KOH、Ba(OH)2、澄清石灰水中的 Ca(OH)2；可溶性盐
🚫 不拆单质、氧化物、气体、沉淀、水；弱酸（H2CO3、CH3COOH、HClO）、弱碱（NH3·H2O）；弱酸的酸式酸根 HCO3-

离子反应发生的条件：生成沉淀、气体或水（难电离物质），本质是溶液中某些离子浓度减小。

💡 老师讲透离子方程式的灵魂是“拆”：只有易溶且易电离的物质（强酸、强碱、可溶性盐）才拆成离子；沉淀、气体、水、氧化物、单质、弱酸弱碱都写化学式。最后“查”两个守恒：原子守恒、电荷守恒。

📌 离子共存：会“打架”的不能待在一起

  • 生成沉淀：Ba2+ 与 SO42-/CO32-；Ag+ 与 Cl-；Ca2+ 与 CO32-；Cu2+、Fe3+、Mg2+ 与 OH-
  • 生成气体：H+ 与 CO32-、HCO3-
  • 生成水/弱电解质：H+ 与 OH-；OH- 与 HCO3-；H+ 与 CH3COO-、ClO-
  • 题目隐含条件：“无色”“酸性”“碱性”——详见 易错与解题模型
💡 老师讲透离子共存的本质：能反应就不能大量共存。反应分四类：生成沉淀、气体、水（弱电解质），发生氧化还原。题干里的隐含条件（无色、酸性、碱性、“与 Al 反应放 H₂”）是最大的坑。
🖼️ 图解
✏️ 例题在 pH = 1 的溶液中，能大量共存的一组离子是（　）A. Na⁺、K⁺、OH⁻、Cl⁻　B. Ba²⁺、Na⁺、SO₄²⁻、NO₃⁻　C. K⁺、Mg²⁺、Cl⁻、SO₄²⁻　D. Na⁺、K⁺、CO₃²⁻、Cl⁻
点我看解析
选 C。pH = 1 为强酸性：A 中 OH⁻ ✗；B 中 Ba²⁺ 与 SO₄²⁻ 生成沉淀 ✗；D 中 CO₃²⁻ ✗。
⚠️ 易错提醒“透明”不等于“无色”：含 Cu²⁺ 的蓝色溶液也是透明的。

📌 氧化还原反应：电子的“交接仪式”

  • 特征：元素化合价有升降；本质：电子转移（得失或偏移）
  • 还原剂：失电子 → 化合价升高 → 被氧化 → 发生氧化反应 → 得到氧化产物
  • 氧化剂：得电子 → 化合价降低 → 被还原 → 发生还原反应 → 得到还原产物
  • 强弱规律：氧化性 氧化剂 > 氧化产物；还原性 还原剂 > 还原产物
  • 常见氧化剂：O2、Cl2、浓 H2SO4、HNO3、KMnO4、FeCl3；常见还原剂：活泼金属、C、H2、CO

升失氧，降得还

（化合价升高、失电子、被氧化；降低、得电子、被还原）

若说剂，正相反

💡 老师讲透氧化还原只看一件事：化合价有没有变。口诀“升失氧、降得还”：化合价升高 → 失电子 → 被氧化 → 作还原剂；化合价降低 → 得电子 → 被还原 → 作氧化剂。氧化剂具有氧化性，“它自己被还原了”。
🖼️ 图解
✏️ 例题在 Fe + CuSO₄ = FeSO₄ + Cu 中，指出氧化剂、还原剂、氧化产物、还原产物。
点我看解析
氧化剂 CuSO4（Cu：+2 → 0），还原剂 Fe（0 → +2），氧化产物 FeSO4，还原产物 Cu。由此还可得：氧化性 Cu²⁺ > Fe²⁺，还原性 Fe > Cu。
⚠️ 易错提醒有单质参加或生成的反应不一定是氧化还原反应：3O₂ = 2O₃（放电）中化合价没变。

🔬 双线桥与单线桥

① 双线桥（同种元素“从左连到右”，标得失）

② 单线桥（从还原剂失电子的元素指向氧化剂得电子的元素，只标总数，不写得失）

CuO + H2△Cu + H2O

得失电子数相等：Cu 得 2e⁻ = 2 个 H 共失 2×e⁻。这就是后面配平用的“得失电子守恒”。

💡 老师讲透双线桥“三要素”：① 箭头从反应物指向生成物中的同一种元素；② 桥上写“得/失 a×be⁻”；③ 得失电子总数相等。单线桥只画一根：从还原剂中失电子的元素指向氧化剂中得电子的元素，只写总数，不写“得失”。
✏️ 例题用双线桥分析 MnO₂ + 4HCl(浓) =△= MnCl₂ + Cl₂↑ + 2H₂O，转移电子数是多少？
点我看解析
Mn：+4 → +2，得 2e⁻；Cl：−1 → 0，失 2×e⁻。每生成 1 mol Cl2 转移 2 mol 电子。
⚠️ 易错提醒单线桥的箭头在反应物之间，不指向生成物；且不标“得”“失”。

🔬 氧化还原与四大基本反应类型

  • 置换反应一定是氧化还原反应
  • 复分解反应一定不是
  • 有单质参加的化合反应、有单质生成的分解反应是
💡 老师讲透四大基本反应类型与氧化还原的关系，用韦恩图一眼看清：置换一定是，复分解一定不是，化合、分解“有单质参加或生成的才是”。
✏️ 例题下列反应既是化合反应又是氧化还原反应的是（　）A. CaO + H₂O = Ca(OH)₂　B. 2H₂ + O₂ =点燃= 2H₂O　C. 2KClO₃ = 2KCl + 3O₂↑　D. NaOH + HCl = NaCl + H₂O
点我看解析
选 B。A 化合但无价态变化；C 分解且氧化还原；D 复分解。
⚠️ 易错提醒“有单质生成的分解反应一定是氧化还原反应”是对的；但“氧化还原反应一定有单质参加”是错的。

⚠️ 易错点

  • ✗ NaCl 溶液能导电，所以 NaCl 溶液是电解质✓ 溶液是混合物；NaCl 才是电解质
  • ✗ CO₂ 溶于水能导电，所以 CO₂ 是电解质✓ 导电的是 H₂CO₃ 电离的离子，CO₂ 是非电解质
  • ✗ 碳酸钙与盐酸：CO₃²⁻ + 2H⁺ = H₂O + CO₂↑✓ CaCO₃ 难溶不拆：CaCO₃ + 2H⁺ = Ca²⁺ + H₂O + CO₂↑
  • ✗ 胶体与溶液的本质区别是丁达尔效应✓ 本质区别是分散质粒子直径大小
  • ✗ 氧化剂发生氧化反应✓ 氧化剂被还原，发生还原反应
  • ✗ 有单质参加的反应一定是氧化还原反应✓ O₂ 转化为 O₃ 不是氧化还原反应

🔬 物质的量：以 n 为中心的换算

  • 阿伏加德罗常数 NA ≈ 6.02×1023 mol−1：1 mol 任何粒子含 NA 个
  • 摩尔质量 M：单位 g/mol，数值等于相对分子（原子）质量，如 M(H2O) = 18 g/mol
  • 气体摩尔体积 Vm：标准状况（0 ℃、101 kPa）下约为 22.4 L/mol，只适用于气体
  • 物质的量浓度 c = n / V(溶液)，单位 mol/L；稀释：c浓V浓 = c稀V稀
  • 同温同压下，相同体积的任何气体含有相同数目的分子（阿伏加德罗定律）
💡 老师讲透物质的量是一座“桥”：一边连宏观的质量、体积、浓度，一边连微观的粒子数。四个公式其实就一句话：先求 n，再求别的。n = m/M = N/NA = V/Vm = c·V。
✏️ 例题标准状况下，6.72 L NH3 的物质的量、质量、所含 H 原子数各是多少？
点我看解析
n = 6.72 ÷ 22.4 = 0.3 mol；m = 0.3 × 17 = 5.1 g；H 原子 0.9 mol，即 0.9NA ≈ 5.42×10²³ 个。
⚠️ 易错提醒Vm = 22.4 L/mol 只适用于标准状况下的气体；摩尔质量的单位是 g/mol，不是 g。

✏️ 算一算：4.4 g CO₂

n = m / M = 4.4 g ÷ 44 g/mol = 0.1 mol

N = n·NA = 0.1 × 6.02×1023 = 6.02×1022 个分子，含 O 原子 0.2 mol

标况下 V = n·Vm = 0.1 × 22.4 = 2.24 L

溶液：把 5.85 g NaCl 配成 100 mL 溶液，c = 0.1 mol ÷ 0.1 L = 1.00 mol/L

质量分数 ↔ 物质的量浓度：c = 1000ρw / M（ρ 单位 g/cm³）

💡 老师讲透计算题的“三步法”：① 把已知量全换成 n；② 用化学式或方程式找 n 的关系；③ 把 n 换成题目要的量。草稿上画出 m → n → N 的箭头，几乎不会出错。

铁是“会变脸”的元素：0 价的铁单质、+2 价的亚铁（浅绿色）、+3 价的铁（棕黄色），三者之间可以互相转化，这就是著名的“铁三角”。理解铁三角的钥匙就是第一章学的氧化还原：往高价走需要氧化剂，往低价走需要还原剂。本章还认识一个“两面派”——铝，它既能和酸反应又能和碱反应。

📋 Fe³⁺ 与 Fe²⁺ 的检验

离子方法现象
Fe3+加 KSCN 溶液溶液变红色
Fe3+加 NaOH 溶液红褐色沉淀
Fe2+先加 KSCN 溶液，再加氯水先无明显变化，后变红色
Fe2+加 NaOH 溶液白色沉淀 → 灰绿 → 红褐色
Fe2+加酸性 KMnO4 溶液紫红色褪去

顺序不能反：检验 Fe2+ 要先加 KSCN 后加氯水，否则无法排除原溶液中的 Fe3+。

💡 老师讲透检验 Fe³⁺ 首选 KSCN 溶液（变红）；检验 Fe²⁺ 用“先 KSCN 不变色，再加氯水变红”，或用 NaOH 溶液看颜色变化，或用酸性 KMnO₄（褪色，但要排除 Cl⁻ 干扰）。
✏️ 例题某溶液中可能含 Fe²⁺、Fe³⁺，如何证明它同时含有两种离子？
点我看解析
取两份：一份加 KSCN 溶液变红 → 含 Fe³⁺；另一份滴加酸性 KMnO₄ 溶液（或铁氰化钾溶液），紫色褪去（或生成蓝色沉淀）→ 含 Fe²⁺。不能用“KSCN + 氯水”法，因为 Fe³⁺ 已经使溶液变红。
⚠️ 易错提醒“滴加氯水再加 KSCN 变红”不能说明原溶液含 Fe²⁺——可能原本就有 Fe³⁺。顺序必须是先 KSCN 后氯水。

📌 金属材料：合金

  • 合金：两种或以上金属（或金属与非金属）熔合而成，具有金属特性
  • 合金硬度一般大于成分金属，熔点一般低于成分金属
  • 铁合金：生铁含碳 2%~4.3%，钢含碳 0.03%~2%；不锈钢中加入 Cr、Ni
  • 铝合金：硬铝（含 Cu、Mg、Mn、Si）密度小、强度高，用于飞机、高铁
  • 新型合金：储氢合金、钛合金、形状记忆合金
💡 老师讲透合金的“两大一小”：硬度大、强度大，熔点一般比各成分金属低。合金是混合物，保留了各成分金属的化学性质。

✏️ 物质的量用于化学方程式计算

系数之比 = 物质的量之比 =（同温同压）气体体积之比

例：5.4 g Al 与足量 NaOH 溶液反应，标准状况下生成 H2 多少升？

n(Al) = 5.4 g ÷ 27 g/mol = 0.2 mol

2Al + 2NaOH + 6H2O2Na[Al(OH)4] + 3H2↑
2 mol3 × 22.4 L
0.2 molV

V = 0.2 × 3 × 22.4 ÷ 2 = 6.72 L

口诀：上下单位一致，左右相当——同一物质上下用同一单位，不同物质可以用不同单位。

💡 老师讲透方程式计算升级为“物质的量版”：上下单位相同，左右单位相当。比如上面写 2 mol，下面就写 n(Al)；上面写 3×22.4 L，下面就写 V(H2)。

📌 原子结构与核外电子排布

AZX　质量数 A = 质子数 Z + 中子数 N

  • 如 3717Cl：质子数 17，中子数 37 − 17 = 20，电子数 17
  • 核外电子排布：由内向外、能量由低到高分层排布
  • 每层最多容纳 2n² 个电子；最外层不超过 8 个（K 层为最外层时不超过 2 个）；次外层不超过 18 个
  • 阳离子：电子数 = 质子数 − 电荷数；阴离子：电子数 = 质子数 + 电荷数
💡 老师讲透核外电子排布的三条规则：① 能量最低（先内后外）；② 每层最多 2n² 个；③ 最外层不超过 8 个（K 层为最外层时不超过 2 个），次外层不超过 18 个。最外层电子数决定化学性质：少于 4 个易失电子，多于 4 个易得电子。
✏️ 例题画出 S 和 S²⁻ 的结构示意图，它们的核电荷数、电子数分别是多少？
点我看解析
S：+16，2, 8, 6；S²⁻：+16，2, 8, 8。核电荷数都是 16，电子数分别为 16 和 18。
⚠️ 易错提醒离子的核电荷数不变，变的只是核外电子数：阳离子“失”，阴离子“得”。

📌 元素、核素、同位素

  • 元素：质子数相同的一类原子的总称
  • 核素：具有一定数目质子和中子的一种原子
  • 同位素：质子数相同而中子数不同的同一元素的不同核素互称同位素
  • 氢的三种核素：11H 氕、21H 氘（D）、31H 氚（T）
  • 126C 是相对原子质量的标准；146C 用于考古断代；23592U 是核燃料
  • 同位素化学性质几乎相同，物理性质有差异

分清“四同”：同位素（原子）、同素异形体（单质，如 O2 与 O3）。

💡 老师讲透“三素”辨析：元素（质子数相同的一类原子）、核素（一定质子数和中子数的一种原子）、同位素（质子数相同、中子数不同的核素互称）。同位素化学性质几乎相同。

🔬 元素周期表与递变规律

  • 7 个周期（1、2、3 短周期，元素数 2、8、8）；18 个纵列 16 个族：7 个主族、7 个副族、第 Ⅷ 族、0 族
  • 周期序数 = 电子层数；主族序数 = 最外层电子数 = 最高正价（O、F 除外）
  • 非金属：最高正价 + |最低负价| = 8
💡 老师讲透周期表“横行看周期，竖列看族”：周期序数 = 电子层数，主族序数 = 最外层电子数。同周期从左到右金属性减弱、非金属性增强；同主族从上到下金属性增强、非金属性减弱。

⚠️ 易错提醒周期表有 7 个周期、16 个族（7 个主族、7 个副族、第 Ⅷ 族、0 族），第 Ⅷ 族占 3 列。

⚗️ 碱金属：越往下越“急”

  • Li、Na、K、Rb、Cs：最外层都是 1 个电子，易失电子，化学性质相似
  • 从上到下：电子层数增多 → 原子半径增大 → 失电子能力增强 → 金属性增强，与水反应越来越剧烈
4Li + O2△2Li2O锂只生成 Li₂O
2Na + O2△Na2O2
2K + 2H2O2KOH + H2↑比钠更剧烈，轻微爆炸
💡 老师讲透碱金属“越往下越急”：电子层数增多、原子半径增大、失电子能力增强 → 与水反应越来越剧烈，Li 在氧气中燃烧只生成 Li2O，Na 生成 Na2O2，K 生成更复杂的氧化物。

⚗️ 卤族元素：越往下越“温和”

  • F、Cl、Br、I：最外层 7 个电子，易得电子
  • 单质颜色加深：F2 淡黄绿色 → Cl2 黄绿色 → Br2 深红棕色液体 → I2 紫黑色固体；熔沸点升高
  • 与 H2 化合越来越难，氢化物稳定性 HF > HCl > HBr > HI，非金属性减弱
Cl2 + 2KBr2KCl + Br2
Cl2 + 2KI2KCl + I2
Br2 + 2KI2KBr + I2
Cl2 + 2Br-2Cl- + Br2离子方程式

氧化性 Cl2 > Br2 > I2；淀粉遇 I2 变蓝。

💡 老师讲透卤素“越往下越温和”：非金属性减弱 → 单质氧化性 F₂ > Cl₂ > Br₂ > I₂，与 H2 化合越来越难，氢化物稳定性 HF > HCl > HBr > HI。所以“上面的”能把“下面的”从盐溶液中置换出来。

📌 化学键：原子之间的“胶水”

  • 离子键：阴、阳离子之间的静电作用——活泼金属与活泼非金属（NaCl、MgCl2），铵盐中也有
  • 共价键：原子间通过共用电子对形成——同种原子间为非极性键（Cl–Cl），不同原子间为极性键（H–Cl）
  • 离子化合物：含离子键（可能还含共价键，如 NaOH、Na2O2、NH4Cl）
  • 共价化合物：只含共价键（HCl、H2O、CO2）
  • 化学反应的本质：旧化学键断裂、新化学键形成
💡 老师讲透化学键分两类：离子键（阴阳离子间的静电作用，一般活泼金属 + 活泼非金属）、共价键（共用电子对，一般非金属之间）。含离子键的化合物就是离子化合物；只含共价键的化合物才是共价化合物。
🖼️ 图解
✏️ 例题判断 NaOH、Na2O2、NH4Cl、H2O2 中所含化学键类型，并指出哪些是离子化合物。
点我看解析

⚠️ 易错提醒稀有气体分子中没有化学键；AlCl3 是共价化合物。

📌 分子间作用力与氢键

  • 分子间作用力（范德华力）比化学键弱得多，影响物质的熔点、沸点等物理性质
  • 组成和结构相似的分子，相对分子质量越大，分子间作用力越大，熔沸点越高：F2 < Cl2 < Br2 < I2
  • 氢键：存在于 H2O、NH3、HF 等分子之间，使它们熔沸点“反常”偏高（H2O 沸点高于 H2S）；冰的密度比水小也与氢键有关
  • 氢键不是化学键，属于一种较强的分子间作用
💡 老师讲透分子间作用力（范德华力）比化学键弱得多，影响物质的熔沸点等物理性质。氢键是一种较强的分子间作用力，存在于 HF、H2O、NH3 等分子之间，使它们的沸点“反常”偏高。

✏️ 例题为什么 H2O 的沸点比 H2S 高？冰为什么浮在水面上？
点我看解析

⚠️ 易错提醒“H2O 比 H2S 稳定是因为有氢键”错：稳定性由化学键（O–H 比 S–H 牢）决定，与氢键无关。

📌 模型① 离子共存：四看清单

  1. 一看颜色：题目说“无色”→ 排除 Cu2+（蓝）、Fe3+（棕黄）、Fe2+（浅绿）、MnO4-（紫红）
  2. 二看酸碱性：酸性溶液（含 H+）不能有 OH-、CO32-、HCO3-、ClO-；碱性溶液（含 OH-）不能有 H+、NH4+、Mg2+、Cu2+、Fe3+、Fe2+、Al3+、HCO3-
  3. 三看反应：能否生成沉淀、气体、水；能否发生氧化还原（Fe2+ 与 MnO4-/ClO-、H++NO3- 不共存）
  4. 四看特殊：HCO3- 遇酸遇碱都不能大量存在

A. K+、Na+、Cl-、SO42-　B. Cu2+、Na+、Cl-、SO42-

B 有颜色 ✗；C 中 CO32- 遇 H+ ✗；D 中 OH- 遇 H+ ✗ → 选 A

📌 模型② 氧化还原配平：得失电子守恒

🏷️ 标价态标出变价元素📈 列变化每个原子升/降几价⚖️ 求相等最小公倍数使得失相等👀 配其余观察法配平，再查守恒

例1：MnO₂ + HCl(浓) → MnCl₂ + Cl₂ + H₂O

Mn：+4 → +2，得 2e⁻；Cl：−1 → 0，生成 1 个 Cl₂ 失 2×e⁻ → 得失已相等，MnO₂ 与 Cl₂ 都配 1

再看 Cl 原子：MnCl₂ 中 2 个 + Cl₂ 中 2 个 = 4 个 → 4HCl，H₂O 配 2

MnO2 + 4HCl(浓)△MnCl2 + Cl2↑ + 2H2O

4 个 HCl 中只有 2 个被氧化（作还原剂），另外 2 个起酸的作用。

例2：KMnO₄ + HCl(浓) → KCl + MnCl₂ + Cl₂ + H₂O

Mn：+7 → +2，得 5e⁻；生成 1 个 Cl₂ 失 2e⁻；最小公倍数 10 → 2KMnO₄、5Cl₂

Cl 原子：2KCl + 2MnCl₂ + 5Cl₂ 共 2 + 4 + 10 = 16 → 16HCl，H₂O 配 8

2KMnO4 + 16HCl(浓)2KCl + 2MnCl2 + 5Cl2↑ + 8H2O

计算题秒杀：氧化剂得电子总数 = 还原剂失电子总数

💡 老师讲透配平的核心永远是“得失电子守恒”，离子方程式还要加上电荷守恒。复杂反应先找出变价元素，用最小公倍数定氧化剂和还原剂的系数，剩下的按原子守恒观察配平。
🖼️ 图解
✏️ 例题配平离子方程式：MnO₄⁻ + Fe²⁺ + H⁺ → Mn²⁺ + Fe³⁺ + H₂O
点我看解析
MnO4- + 5Fe2+ + 8H+Mn2+ + 5Fe3+ + 4H2O

Mn 得 5e⁻，Fe 失 1e⁻ → Fe²⁺ 配 5；再由电荷守恒定 H⁺ 为 8。

⚠️ 易错提醒离子方程式只配平原子而不查电荷是最常见的丢分点。

  • ✗ 1 mol Na₂O₂ 中含离子总数 4NA✓ Na₂O₂ 由 2Na⁺ 和 1 个 O₂²⁻ 构成，离子总数 3NA
  • ✗ 1 mol Na₂O₂ 与足量 CO₂ 反应转移 2NA 个电子✓ O 由 −1 价一半升一半降，转移 NA 个电子
  • ✗ 1 mol Fe 与足量 Cl₂ 反应转移 2NA 个电子✓ 生成 FeCl₃，转移 3NA 个电子
  • ✗ 1 mol 氦气含 2NA 个原子✓ 稀有气体是单原子分子，含 NA 个原子

✅ 不受状况影响的：质量、物质的量、粒子数——“18 g H₂O 在任何条件下都含 NA 个分子”是对的；32 g O₂ 与 O₃ 的混合物含 2NA 个 O 原子也对。1 mol Cl₂ 与足量 NaOH 反应转移 NA 个电子（歧化）。

💡 老师讲透NA 题的“排雷顺序”：① 看状态（标况、是否气体）；② 看组成（单原子分子、特殊结构如 Na2O2）；③ 看反应（转移电子、可逆反应不能进行到底）；④ 看溶液（有无体积、弱电解质部分电离）。

💡 老师讲透误差分析一律回到 c = n/V：让 n 偏大或 V 偏小的操作 → 偏高；让 n 偏小或 V 偏大的操作 → 偏低。称量时“左码右物”只有使用了游码才会有误差。
✏️ 例题用 NaOH 固体配制溶液时，把 NaOH 放在滤纸上称量，结果偏高还是偏低？
点我看解析
偏低。NaOH 易潮解，会吸收水分并粘在滤纸上，称得的 NaOH 实际偏少（n 偏小）。应放在小烧杯中称量。
⚠️ 易错提醒定容时俯视 → V 偏小 → 浓度偏高；仰视 → 偏低。和量筒“量取”时的仰视俯视结论刚好相反。

📌 模型⑤ 以物质的量为中心的计算

  • 无论题目给的是质量、体积、粒子数还是浓度，第一步都先换算成 n
  • 方程式中用系数比找 n 的关系，最后再换算成题目要的量
  • 多步反应找“关系式”：如 2Al ~ 3H2；MnO2 ~ Cl2
  • 守恒法：原子守恒、电荷守恒、得失电子守恒，能省掉大量计算
💡 老师讲透以 n 为中心的计算常用三种“捷径”：关系式法（多步反应找首尾）、守恒法（原子、电荷、电子）、差量法（质量或体积差）。
