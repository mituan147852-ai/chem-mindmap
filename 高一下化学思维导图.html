🏭 第5章 化工生产中的重要非金属元素

硫 · 氮 · 硅：从火山口到化肥厂，再到芯片

👩‍🏫
想象你站在一座火山口：刺鼻的气味是 SO2，岩石上黄色的粉末是硫。再想象一道闪电劈下，空气里的 N2 和 O2 被“撮合”成 NO——这就是大自然在“固氮”。这一章的主角就是硫、氮、硅三位非金属“大咖”。学它们只用一张图：价类二维图——横着看“它是什么类别”，竖着看“它是几价”。横着走用复分解，竖着走用氧化还原，高一上的两把钥匙全用上了。

🧱 前置地基：先确认这些会了

  • 氧化还原升失氧、降得还；价态升降判断氧化剂、还原剂高一上·氧化还原 ↗
  • 离子方程式写拆删查（硝酸与铜、SO₄²⁻ 检验都要写离子方程式）高一上·离子方程式 ↗
  • 物质的量n、Vm、c 的换算（硫酸、硝酸计算题）高一上·物质的量 ↗
  • 氯气Cl₂ 的强氧化性、氯水漂白（和 SO₂ 漂白对比）高一上·氯气 ↗
  • 酸的通性酸 + 金属/金属氧化物/碱/盐初中③身边的物质 ↗

📌 硫单质：黄色的“硫黄”

  • 淡黄色晶体，俗称硫黄；难溶于水，微溶于酒精，易溶于 CS2（试管壁上的硫用 CS2 洗）
  • 火山口附近有游离态硫；化合态硫存在于硫化物（如 FeS2）和硫酸盐中
  • 弱氧化性：与变价金属反应只生成低价硫化物（对比 Cl2 把 Fe 氧化成 +3 价）
Fe + S△FeS
2Cu + S△Cu2S
H2 + S△H2S

还原性：

S + O2点燃SO2空气中淡蓝色火焰，纯氧中蓝紫色火焰
💡 老师讲透：硫的氧化性比氯气弱，所以同样和铁、铜反应，Cl2 能把它们“拉”到高价（FeCl3、CuCl2），硫只能拉到低价（FeS、Cu2S）。这就是用“产物价态”比较氧化性强弱的经典证据。
✏️ 例题　下列物质不能由单质直接化合生成的是（　）A. FeS　B. CuS　C. SO2　D. FeCl3
点我看解析

选 B。S 与 Cu 化合只生成 Cu2S（Cu 为 +1 价）；Fe 与 S 生成 FeS；Fe 与 Cl2 直接生成 FeCl3。

⚠️ 易错提醒：S 在纯氧中燃烧也只生成 SO2，不会一步生成 SO3。

⚗️ 二氧化硫：会“变脸”的气体

无色、有刺激性气味、有毒、易溶于水（1:40）、易液化。它有四张脸：

① 酸性氧化物（可逆反应）

SO2 + H2O⇌H2SO3
SO2 + 2NaOHNa2SO3 + H2O
SO2 + CaOCaSO3

② 还原性（+4 → +6，最主要的性质）

2SO2 + O2催化剂⇌△2SO3
SO2 + Cl2 + 2H2OH2SO4 + 2HCl
SO2 + Br2 + 2H2OH2SO4 + 2HBr使溴水、酸性 KMnO₄ 溶液褪色 → 还原性，不是漂白！

③ 氧化性（+4 → 0）

SO2 + 2H2S3S + 2H2O

④ 漂白性：使品红溶液褪色，加热后恢复红色（与有色物质化合成不稳定的无色物质）；不能使石蕊褪色，只能使其变红

SO2 漂白HClO / Na2O2 / O3 漂白
原理化合成不稳定的无色物质强氧化性
可逆？加热恢复原色不可逆
💡 老师讲透：判断 SO2 表现什么性质，看对方是谁：遇碱 → 酸性氧化物；遇强氧化剂（O2、Cl2、溴水、酸性 KMnO₄、H2O2）→ 还原性；遇 H2S → 氧化性；遇品红 → 漂白性。
✏️ 例题　把 SO2 通入下列溶液，溶液都会褪色：①品红溶液 ②溴水 ③酸性 KMnO₄ 溶液 ④滴有酚酞的 NaOH 溶液。分别体现 SO2 的什么性质？
点我看解析

① 漂白性；② ③ 还原性；④ 酸性氧化物的性质（中和了 NaOH，碱性消失）。

⚠️ 易错提醒：SO2 不能漂白酸碱指示剂：通入紫色石蕊溶液只变红、不褪色。

⚗️ 硫酸与浓硫酸的特性

工业制硫酸三步：造气 → 催化氧化 → 吸收（用 98.3% 浓硫酸吸收 SO3，防止形成酸雾）

4FeS2 + 11O2高温2Fe2O3 + 8SO2
2SO2 + O2催化剂⇌△2SO3
SO3 + H2OH2SO4
💧 吸水性作干燥剂；不能干燥 NH3、H2S🖤 脱水性蔗糖变黑膨胀成“黑面包”，按 2:1 夺走 H、O🔥 强氧化性加热时氧化 Cu、C，自身还原为 SO2🛡️ 钝化常温下使 Fe、Al 表面钝化，可用铁/铝罐储运
Cu + 2H2SO4(浓)△CuSO4 + SO2↑ + 2H2O既表现氧化性又表现酸性
C + 2H2SO4(浓)△CO2↑ + 2SO2↑ + 2H2O只表现氧化性

⚠️ 稀释浓硫酸：酸入水、沿器壁、慢慢倒、不断搅。Cu 与浓硫酸反应时，硫酸变稀后反应停止，所以实际生成的 SO2 比按方程式算的少。

💡 老师讲透：浓硫酸的三大特性要会“对号入座”：吸水性夺走的是现成的水分子（物理过程为主），脱水性是把有机物中的 H、O 按 2:1 夺走（化学变化），强氧化性是 +6 价 S 得电子变成 SO2。
✏️ 例题　蔗糖中加入浓硫酸，蔗糖变黑、体积膨胀，并闻到刺激性气味。这一现象体现了浓硫酸的哪些性质？
点我看解析

变黑 → 脱水性；放热使水汽化、产生 SO2（刺激性气味）和 CO2 使其膨胀 → 强氧化性（C + 2H2SO4(浓) → CO2↑ + 2SO2↑ + 2H2O）；同时还有吸水性。

⚠️ 易错提醒：“浓硫酸使胆矾变白”体现的是吸水性，不是脱水性（胆矾中本来就有结晶水）。

📌 SO₄²⁻ 的检验与粗盐提纯

  1. 取少量待测液，先加稀盐酸酸化，无明显现象（排除 CO32-、SO32-、Ag+ 的干扰）
  2. 再加 BaCl2 溶液，产生白色沉淀 → 含 SO42-
Ba2+ + SO42-BaSO4↓

粗盐提纯（除去 Ca2+、Mg2+、SO42-）：

过量 BaCl2 → 过量 NaOH → 过量 Na2CO3 → 过滤 → 适量盐酸

关键：Na2CO3 必须在 BaCl2 之后（顺便除掉多余的 Ba2+）；盐酸必须在过滤之后（否则沉淀又溶解）。NaOH 的位置可以灵活。

💡 老师讲透：检验离子的通用答题模板：取样 → 加试剂 → 描述现象 → 得出结论。SO42- 检验中，“先加稀盐酸”这一步既是为了排除干扰，也保证溶液是酸性的。
✏️ 例题　某同学向溶液中先加 BaCl2 溶液产生白色沉淀，再加稀盐酸沉淀不溶解，就认为一定含 SO42-。这个结论可靠吗？
点我看解析

不可靠：若溶液中含 Ag+，会生成不溶于盐酸的 AgCl 白色沉淀。正确顺序是先加稀盐酸无现象，再加 BaCl2。

⚠️ 易错提醒：不能用稀硝酸酸化（会把 SO32- 氧化成 SO42-），也不能用 Ba(NO3)2 代替 BaCl2。

🔬 含硫物质的转化：硫的价类二维图

硫的价态有四级：−2、0、+4、+6

向上走靠氧化剂（O2、Cl2、浓硝酸），向下走靠还原剂

同价之间换“类别”：酸性氧化物 → 酸 → 盐，用碱就能走

主线：S → SO2 → SO3 → H2SO4 → Na2SO4；+4 价的 SO2、H2SO3、Na2SO3 处于中间价态，既有氧化性又有还原性，以还原性为主（Na2SO3 久置会变质成 Na2SO4）。

💡 老师讲透：价类二维图的两条“走法”：竖着走（价态变）必须找氧化剂或还原剂；横着走（类别变、价态不变）用酸、碱、水等就行。考题给一个陌生物质，先定位它在图中的“坐标”，性质就推出来了。
✏️ 例题　Na2SO3 在空气中久置会变质。写出变质的化学方程式，并说出如何检验它是否已经变质。
点我看解析

2Na2SO3 + O2 = 2Na2SO4。取样，加入足量稀盐酸（除去 SO32-），再加 BaCl2 溶液，若产生白色沉淀，说明已变质。

⚠️ 易错提醒：+4 价的硫以还原性为主，但遇到 H2S（−2 价）时表现氧化性。

⚗️ 氮气与氮的氧化物

  • N2 中含 N≡N 三键，键能大，常温下很稳定（作保护气、食品充氮）
  • 氮的固定：游离态 → 化合态。自然固氮（雷电、豆科植物根瘤菌）；人工固氮（合成氨）
  • NO：无色、难溶于水，只能用排水法收集；NO2：红棕色、有刺激性气味、易溶于水，用向上排空气法收集
N2 + O2放电或高温2NO
2NO + O22NO2无色 → 红棕色
3NO2 + H2O2HNO3 + NONO2 既是氧化剂又是还原剂
N2 + 3H2高温、高压⇌催化剂2NH3合成氨（人工固氮）
💡 老师讲透：N2 很“懒”是因为 N≡N 三键很牢。要让它反应，必须给足能量：闪电（放电）、高温高压加催化剂。NO 和 NO2 是一对“兄弟”：NO 一见 O2 就变红棕色的 NO2，NO2 一见水又变回一部分 NO。
✏️ 例题　将充满 NO2 的试管倒立于水槽中，充分反应后，试管内液面上升到什么位置？剩余气体是什么？
点我看解析

由 3NO2 + H2O = 2HNO3 + NO，3 体积 NO2 只剩 1 体积 NO，液面上升到试管容积的 2/3 处，剩余气体为 NO。

⚠️ 易错提醒：NO2 与水反应中，NO2 既是氧化剂又是还原剂，氧化剂与还原剂的物质的量之比为 1:2。

🔬 氨气与喷泉实验

  • 无色、有刺激性气味，密度比空气小，极易溶于水（1:700），易液化（液氨作制冷剂）
  • 喷泉原理：气体迅速溶解（或反应）→ 瓶内压强骤减 → 外界大气压把水压入。HCl、SO2+NaOH 溶液也能形成喷泉
NH3 + H2O⇌NH3·H2O
NH3·H2O⇌NH4+ + OH-氨水呈弱碱性
NH3 + HClNH4Cl产生白烟（蘸浓氨水与浓盐酸的玻璃棒靠近）
4NH3 + 5O2催化剂△4NO + 6H2O氨的催化氧化，工业制硝酸第一步
💡 老师讲透：喷泉的关键是“瓶内压强迅速变小”：气体极易溶于水（NH3、HCl），或能被溶液大量吸收（CO2、SO2 遇 NaOH 溶液）。喷泉颜色由“气体溶液 + 指示剂”决定。
✏️ 例题　用 HCl 气体做喷泉实验，烧杯中盛滴有紫色石蕊的水，会看到什么颜色的喷泉？若改用 CO2 和水能否形成喷泉？
点我看解析

HCl 极易溶于水，形成红色喷泉（盐酸使石蕊变红）。CO2 在水中溶解度小，不能形成喷泉；改用浓 NaOH 溶液才可以。

⚠️ 易错提醒：实验失败的常见原因：烧瓶不干燥、气体不纯（没充满）、装置漏气。

⚗️ 氨气的实验室制法

2NH4Cl + Ca(OH)2△CaCl2 + 2NH3↑ + 2H2O
环节做法为什么
装置固 + 固 加热（与制 O2 相同），试管口略向下防止冷凝水倒流使试管炸裂
干燥碱石灰不能用浓硫酸、无水 CaCl2（都会吸收 NH3）
收集向下排空气法，管口塞一团棉花密度比空气小；棉花减少与空气对流
验满/检验湿润的红色石蕊试纸变蓝；或蘸浓盐酸的玻璃棒产生白烟NH3 溶于水显碱性

快速制氨：浓氨水加热，或浓氨水滴到生石灰/NaOH 固体上。不能只加热 NH4Cl（分解生成的 NH3 和 HCl 在管口又化合）。

💡 老师讲透：实验室制氨的装置和制 O2（KMnO4 加热）一样，是“固 + 固 加热”型。记住三个“不能”：不能用浓硫酸或 CaCl2 干燥、不能用排水法收集、不能只加热 NH4Cl。
✏️ 例题　实验室用 10.7 g NH4Cl 与足量 Ca(OH)₂ 共热，理论上最多能得到标准状况下多少升 NH3？
点我看解析

n(NH4Cl) = 10.7 g ÷ 53.5 g/mol = 0.2 mol，由 2NH4Cl ~ 2NH3，n(NH3) = 0.2 mol，V = 0.2 × 22.4 = 4.48 L。

⚠️ 易错提醒：不用 NaOH 代替 Ca(OH)₂：NaOH 易吸湿结块，加热时还会腐蚀玻璃试管。

⚗️ 铵盐与 NH₄⁺ 的检验

  • 铵盐都是易溶于水的白色晶体
  • 受热易分解；与碱反应放出 NH3（铵态氮肥不能和草木灰等碱性物质混用）
NH4Cl△NH3↑ + HCl↑
NH4HCO3△NH3↑ + H2O + CO2↑

NH4+ 的检验：取样，加 NaOH 溶液并加热，用湿润的红色石蕊试纸检验，试纸变蓝 → 含 NH4+

NH4+ + OH-△NH3↑ + H2O

⚠️ 不加热时稀溶液中只生成 NH₃·H₂O，未必能放出氨气。

💡 老师讲透：铵盐的“两怕”：怕热（受热分解）、怕碱（遇碱放氨）。所以铵态氮肥要阴凉处保存、深施盖土，不能和草木灰（含 K2CO3，显碱性）混用。
✏️ 例题　有 NH4Cl、(NH4)2SO4、NaCl、Na2SO4 四瓶无色溶液，只用一种试剂一次鉴别，应选什么？
点我看解析

选 Ba(OH)₂ 溶液并加热：只有刺激性气体 → NH4Cl；白色沉淀 + 刺激性气体 → (NH4)2SO4；无现象 → NaCl；只有白色沉淀 → Na2SO4。

⚠️ 易错提醒：NH4Cl 受热“升华”是假象：它是先分解、在管口遇冷又重新化合，属于化学变化。

⚗️ 硝酸：强氧化性的“狠角色”

  • 无色、易挥发、有刺激性气味；不稳定，见光或受热分解 → 保存在棕色试剂瓶，置于阴凉处；浓硝酸常显黄色（溶有 NO2）
  • 强氧化性：几乎能氧化所有金属（Au、Pt 除外），浓硝酸 → NO2，稀硝酸 → NO
  • 常温下浓硝酸使 Fe、Al 钝化；与金属反应不产生 H2

🔬 含氮物质的转化：氮的价类二维图

💡 老师讲透：氮的二维图有两条“工业主线”：合成氨（N2 → NH3）和氨氧化法制硝酸（NH3 → NO → NO2 → HNO3）。自然界里“雷雨发庄稼”走的是 N2 → NO → NO2 → HNO3 → 硝酸盐。

📌 键能视角：断键吸热，成键放热

反应热 = 断键吸收的总能量 − 成键放出的总能量（结果为负 → 放热）

例：已知 H–H 436 kJ/mol，Cl–Cl 243 kJ/mol，H–Cl 431 kJ/mol，求 1 mol H2 与 1 mol Cl2 反应的能量变化。

H2 + Cl2点燃2HCl

断键吸收：436 + 243 = 679 kJ

成键放出：2 × 431 = 862 kJ

862 − 679 = 183 kJ → 放出 183 kJ 热量

宏观看总能量，微观看化学键：“能量越低越稳定”，放热反应的生成物更稳定。

💡 老师讲透：从微观看：断开化学键要“花钱”（吸收能量），形成化学键会“赚钱”（放出能量）。赚的比花的多 → 放热。物质越稳定，键能越大、自身能量越低。
✏️ 例题　已知 N≡N 键能 946 kJ/mol，H–H 436 kJ/mol，N–H 391 kJ/mol。计算 1 mol N2 与 3 mol H2 完全反应生成 2 mol NH3 的能量变化。
点我看解析

断键吸收：946 + 3 × 436 = 2254 kJ；成键放出：6 × 391 = 2346 kJ；放出 2346 − 2254 = 92 kJ。

⚠️ 易错提醒：算成键时别漏数：2 个 NH3 共有 6 个 N–H 键。

🔬 原电池原理：铜锌原电池

原电池：把化学能转化为电能的装置；本质是自发的氧化还原反应

Zn − 2e-Zn2+负极：氧化反应
2H+ + 2e-H2↑正极：还原反应
Zn + 2H+Zn2+ + H2↑总反应

构成条件（缺一不可）：① 两个活泼性不同的电极 ② 电解质溶液 ③ 形成闭合回路 ④ 能自发发生氧化还原反应

负失氧，正得还

电子负到正（走导线），电流正到负

阳离子向正极，阴离子向负极（走溶液）

💡 老师讲透：原电池就是把一个氧化还原反应“拆”成两半：失电子的一半在负极，得电子的一半在正极，电子被迫绕道导线——于是有了电流。导线里跑的是电子，溶液里跑的是离子，合起来形成闭合回路。
✏️ 例题　把锌片和铜片用导线连接后插入稀硫酸中，下列说法正确的是（　）A. 铜片是负极　B. 铜片质量逐渐减少　C. 电流从锌片经导线流向铜片　D. H+ 在铜片表面被还原
点我看解析

选 D。Zn 是负极、逐渐溶解；Cu 是正极、质量不变；电流从正极（Cu）流向负极（Zn）；正极上 2H+ + 2e⁻ = H2↑。

⚠️ 易错提醒：酒精、蔗糖溶液不导电，不能作电解质溶液；两极材料相同也不能构成原电池。

📌 化学反应速率：v = Δc / Δt

  • 单位：mol/(L·min) 或 mol/(L·s)；表示的是一段时间内的平均速率
  • 同一反应用不同物质表示，数值可能不同，但意义相同：速率之比 = 化学计量数之比
  • 不能用固体或纯液体表示反应速率（浓度视为常数）

例：在 2 L 密闭容器中发生 N2 + 3H2 ⇌ 2NH3，2 min 内 NH3 增加了 0.8 mol。

v(NH3) = 0.8 mol ÷ 2 L ÷ 2 min = 0.2 mol/(L·min)

v(N2) = 0.2 × 1/2 = 0.1 mol/(L·min)；v(H2) = 0.2 × 3/2 = 0.3 mol/(L·min)

比较快慢：先换成同一物质、同一单位再比。

💡 老师讲透：速率计算“三段式”最稳：写方程式 → 列出起始量、变化量、某时刻量 → 变化量之比 = 计量数之比。比较快慢时一定要换算成同一物质、同一单位。
✏️ 例题　反应 A(g) + 3B(g) ⇌ 2C(g) + 2D(g) 在四种情况下的速率：① v(A) = 0.15 mol/(L·s) ② v(B) = 0.6 mol/(L·s) ③ v(C) = 0.4 mol/(L·s) ④ v(D) = 0.45 mol/(L·s)。哪种最快？
点我看解析

都换算成 v(A)：① 0.15 ② 0.2 ③ 0.2 ④ 0.225，单位 mol/(L·s)，所以 ④ 最快。

⚠️ 易错提醒：单位要统一：0.6 mol/(L·min) = 0.01 mol/(L·s)。

接触面积固体颗粒越小，速率越快煤粉燃烧比煤块快

“控制变量法”：一次只改变一个条件，其他条件保持相同。恒容时充入不参与反应的气体（如 He），各物质浓度不变，速率不变。

💡 老师讲透：影响速率的因素可以用“碰撞”来想：浓度大、压强大 → 单位体积里分子多，碰得勤；温度高 → 分子跑得快、能量高；催化剂 → 把“山”削矮，更多分子能翻过去；颗粒小 → 接触面积大。
✏️ 例题　用锌粒与稀硫酸制 H2，下列措施不能加快反应速率的是（　）A. 加热　B. 改用锌粉　C. 改用 98% 的浓硫酸　D. 滴加少量 CuSO4 溶液
点我看解析

选 C：浓硫酸与 Zn 反应生成 SO2 而不是 H2。D 中 Zn 置换出 Cu，形成 Zn–Cu 原电池，反应加快。

⚠️ 易错提醒：恒压时充入 He，容器体积变大、反应物浓度变小，速率减慢；恒容充入 He 速率不变。

🔬 化学平衡：可逆反应的“限度”

可逆反应：同一条件下同时向正、逆两个方向进行，用 ⇌ 表示；反应物不能完全转化。

逆：研究对象是可逆反应

等：v(正) = v(逆)

动：动态平衡，反应没停

定：各组分浓度保持不变

变：条件改变，平衡被打破

化学反应的限度决定了反应物的最大转化率；改变条件（温度、浓度、压强）可以在一定程度上改变限度。

💡 老师讲透：“平衡”不是反应停了，而是正反应和逆反应“打平了”：每秒生成多少就消耗多少，所以各物质的量不再变。可逆反应永远进行不到底，反应物和生成物同时共存。
✏️ 例题　在密闭容器中进行 2SO2 + O2 ⇌ 2SO3，已知起始 SO2、O2、SO3 的浓度分别为 0.2、0.1、0.2 mol/L。平衡时下列数据可能存在的是（　）A. SO2 为 0.4 mol/L　B. SO2 为 0.25 mol/L　C. SO3 为 0.4 mol/L　D. SO2、SO3 均为 0.15 mol/L
点我看解析

选 B。用“极限法”：反应全部向左，SO2 最多 0.4；全部向右，SO3 最多 0.4，但可逆反应达不到极限，A、C 不可能；D 违背 S 原子守恒（总和应为 0.4）。

⚠️ 易错提醒：平衡时 v(正) = v(逆)，指的是同一物质的生成速率等于消耗速率，不是“正反应速率为 0”。

📌 平衡标志：能不能判断“已达平衡”

  • 直接标志：v(正) = v(逆)——必须一个说正反应、一个说逆反应，且换算成同一物质后相等
  • 间接标志：各组分的浓度、质量分数、物质的量不变；有颜色的物质颜色不变
  • “变量不变”原则：一个物理量如果在反应过程中一直在变，它不变了就说明到平衡；本来就不变的量（如恒容下全是气体时的密度）不能作标志

详细判断见“易错与解题模型③”。

💡 老师讲透：判断标志的口诀：“正逆相等、变量不变”。拿到一个物理量，先问自己：反应进行过程中，它变不变？变 → 不变时可作标志；本来就不变 → 不能作标志。
✏️ 例题　恒温恒容下，C(s) + H2O(g) ⇌ CO(g) + H2(g)，“混合气体的密度不变”能否说明达到平衡？
点我看解析

能。因为有固体 C 参加，反应过程中气体总质量在变，而体积不变，所以密度是变量，密度不变说明达到平衡。

⚠️ 易错提醒：同一个说法，换了反应就可能换了答案：一定要看清物质状态和气体分子数是否变化。

🏠 生活中的能量与速率

  • 🔋 手机锂电池、电动车：化学能 ⇌ 电能
  • 🔥 煤粉燃烧、鼓风吹火：增大接触面积和氧气浓度
  • 🧊 冰箱保鲜、夏天食物易变质：温度影响速率
  • 🏭 合成氨要高温高压加催化剂：既求快，也求“多”
  • 🧪 铁生锈也是原电池（电化学腐蚀），刷漆、镀锌可以防锈
💡 老师讲透：化学反应的条件控制有两个目标：促进有利的反应（加快速率、提高转化率，如工业合成氨、燃料充分燃烧），抑制有害的反应（减慢金属腐蚀、食物变质）。
✏️ 例题　为什么烧煤时要把煤块粉碎，并鼓入适当过量的空气？空气过量太多又有什么坏处？
点我看解析

粉碎增大接触面积、适当过量空气增大 O2 浓度，使燃烧更快更充分；空气过多会带走大量热量，降低热效率。

⚠️ 易错提醒：温度越高速率越快，但高温也可能使催化剂失活、增加能耗，工业上选的是“合适”的温度。

⚠️ 本章易错点

  • ✗ 需要加热的反应都是吸热反应✓ 反应吸放热与条件无关，看总能量（或键能）
  • ✗ 原电池中较活泼的金属一定是负极✓ 看谁失电子：Mg–Al–NaOH 中 Al 是负极
  • ✗ 电子从负极经电解质溶液流向正极✓ 电子只走导线，溶液中靠离子移动导电
  • ✗ 用固体 C 的浓度变化表示反应速率✓ 固体、纯液体不能用来表示速率
  • ✗ 达到平衡时反应停止了✓ 是动态平衡，v(正) = v(逆) ≠ 0
  • ✗ 平衡时各物质浓度之比等于计量数之比✓ 平衡时浓度保持不变，但不一定等于计量数之比

甲烷 · 乙烯 · 乙醇 · 乙酸 · 基本营养物质

你吃的米饭（淀粉）、喝的牛奶（蛋白质）、穿的衣服（纤维）、加进汽车的汽油（烃）……全都是有机物。有机物种类上亿，靠的是碳原子“手拉手”：每个碳伸出 4 只手，可以连成链、连成环，还能双手（双键）紧握。学有机就盯住一个词——官能团：它决定了这一类物质“会做什么反应”。认准官能团，就能举一反三。

🔬 甲烷与乙烯的结构

甲烷乙烯
分子式CH4C2H4
结构简式CH4CH2=CH2（双键不能省）
空间结构正四面体，键角 109°28′平面形，6 个原子共平面
特征反应取代反应加成反应、加聚反应
💡 老师讲透：碳原子的 4 个共价键“方向”决定了分子的形状：4 个单键 → 正四面体（CH4）；有一个双键 → 平面（C2H4）。判断“几个原子共平面”就是以它们为“模板”去拼。
✏️ 例题　CH2Cl2 有几种结构？如果甲烷是平面正方形结构，CH2Cl2 又会有几种？
点我看解析

正四面体中任意两个顶点都相邻，CH2Cl2 只有 1 种结构；若是平面正方形，会有“相邻”和“相对”两种。这正是证明甲烷为正四面体的证据。

⚠️ 易错提醒：甲烷分子中最多只有 3 个原子共平面；乙烯 6 个原子全部共平面。

⚗️ 烷烃：结构与取代反应

  • 烷烃（饱和烃）：碳原子间都以单键结合成链状，通式 CnH2n+2
  • 甲烷是天然气、沼气、可燃冰的主要成分；性质稳定，不使酸性 KMnO₄ 溶液和溴水褪色
CH4 + 2O2点燃CO2 + 2H2O点燃前必须验纯

取代反应：有机物分子里的某些原子或原子团被其他原子或原子团所替代（“有上有下”）

CH4 + Cl2光照⟶CH3Cl + HCl
CH3Cl + Cl2光照⟶CH2Cl2 + HCl
CH2Cl2 + Cl2光照⟶CHCl3 + HCl
CHCl3 + Cl2光照⟶CCl4 + HCl

现象：黄绿色变浅，瓶壁出现油状液滴，液面上升，有白雾。四种取代产物同时生成，HCl 的量最多；CH3Cl 是气体，其余三种是液体。

💡 老师讲透：取代反应就像“换座位”：Cl 原子换下一个 H 原子，被换下的 H 和另一个 Cl 结合成 HCl。所以每取代 1 个 H，就要消耗 1 个 Cl2，同时生成 1 个 HCl。
✏️ 例题　1 mol CH4 与 Cl2 光照下完全反应，生成等物质的量的四种有机取代产物，共消耗 Cl2 多少摩尔？
点我看解析

四种产物各 0.25 mol，取代的 H 数：0.25 × (1 + 2 + 3 + 4) = 2.5 mol，所以消耗 Cl2 2.5 mol。

⚠️ 易错提醒：甲烷只与氯气（气体）在光照下取代，不与氯水反应。

📌 同系物与同分异构体

同系物同分异构体
定义结构相似，分子组成相差一个或若干个 CH2 原子团分子式相同，结构不同
例子CH4、C2H6、C3H8正丁烷 CH3CH2CH2CH3 与异丁烷 CH3CH(CH3)CH3
  • 丁烷有 2 种同分异构体，戊烷有 3 种（正戊烷、异戊烷、新戊烷）
  • 对比“四同”：同位素（原子）、同素异形体（单质）、同系物、同分异构体（化合物）
  • 烷烃随碳原子数增多：熔沸点升高，常温下 C1–C4 为气态
💡 老师讲透：判断“同系物”三要素：同类物质（结构相似）、通式相同、相差若干个 CH2。判断“同分异构体”只看两点：分子式相同、结构不同。
✏️ 例题　下列各组物质互为同分异构体的是（　）A. O2 和 O3　B. CH4 和 C2H6　C. 正丁烷和异丁烷　D. ¹²C 和 ¹³C
点我看解析

选 C。A 同素异形体；B 同系物；D 同位素。

⚠️ 易错提醒：CH3CH2CH3 和 CH3CH(CH3)CH3 是同系物（相差一个 CH2），不是同分异构体。

⚗️ 乙烯：加成反应与加聚反应

  • 无色、稍有气味、难溶于水；石油化工的标志（乙烯产量衡量一个国家的石油化工水平）；植物生长调节剂、催熟剂
  • 加成反应：有机物分子中双键两端的碳原子与其他原子或原子团直接结合（“只上不下”）
CH2=CH2 + Br2⟶CH2BrCH2Br溴的四氯化碳溶液或溴水褪色
CH2=CH2 + H2催化剂⟶△CH3CH3
CH2=CH2 + HCl催化剂⟶△CH3CH2Cl
CH2=CH2 + H2O催化剂⟶加热、加压CH3CH2OH

氧化反应：燃烧火焰明亮并伴有黑烟；能使酸性 KMnO₄ 溶液褪色

C2H4 + 3O2点燃2CO2 + 2H2O

加聚反应：小分子（单体）通过加成反应连成高分子（聚合物）

nCH2=CH2催化剂⟶[ CH2—CH2 ]n聚乙烯；链节 —CH₂—CH₂—，n 为聚合度
💡 老师讲透：双键像“两只手拉在一起”，其中一只手拉得比较松，遇到 Br2、H2、HCl、H2O 就会松开，各接一个原子——这就是加成。很多个乙烯都松开一只手、彼此手拉手，就成了聚乙烯（加聚）。
✏️ 例题　用一种试剂既能鉴别甲烷和乙烯，又能除去甲烷中混有的乙烯，应选什么？
点我看解析

选溴水：乙烯使溴水褪色（鉴别），并生成液态的 1,2-二溴乙烷被除去（除杂）。不用酸性 KMnO₄：它把乙烯氧化成 CO2，引入新杂质。

⚠️ 易错提醒：聚乙烯中已经没有碳碳双键，不能使溴水褪色。

📌 烃与有机高分子材料

  • 烃：只含 C、H 两种元素的有机物——烷烃（饱和）、烯烃（含 C=C）、炔烃（含 C≡C，如乙炔 CH≡CH）、芳香烃（如苯 C6H6）
  • 三大合成材料：塑料（聚乙烯、聚氯乙烯）、合成纤维、合成橡胶
  • 天然高分子：淀粉、纤维素、蛋白质、天然橡胶
  • “白色污染”：废弃塑料难降解 → 减少使用、回收利用、开发可降解塑料
💡 老师讲透：高分子的结构“三件套”：单体（原料小分子）、链节（重复单元）、聚合度 n。由于 n 不确定，高分子都是混合物，没有固定熔点。
✏️ 例题　聚氯乙烯（PVC）的单体是什么？写出其加聚反应的方程式（用结构简式）。
点我看解析

单体是氯乙烯 CH2=CHCl；nCH2=CHCl →（催化剂）[ CH2—CHCl ]n。

⚠️ 易错提醒：聚乙烯可作食品包装袋，聚氯乙烯不能用于包装食品。

⚗️ 乙醇：“酒精”的三种反应

  • 无色、有特殊香味的液体，能与水以任意比互溶；官能团是羟基 —OH，结构简式 CH3CH2OH
  • 用途：燃料、饮料、溶剂、医用消毒（75% 酒精）
2CH3CH2OH + 2Na⟶2CH3CH2ONa + H2↑比 Na 与水反应缓和，钠沉在底部
CH3CH2OH + 3O2点燃2CO2 + 3H2O
2CH3CH2OH + O2Cu或Ag⟶△2CH3CHO + 2H2O催化氧化：铜丝 红 → 黑 → 红

乙醇还能被酸性 KMnO₄ 或酸性 K2Cr2O7 溶液直接氧化为乙酸——酒驾检测仪就是利用 K2Cr2O7（橙色）变为 Cr3+（绿色）。

💡 老师讲透：乙醇的“技能”都来自 —OH：O–H 键断开 → 与 Na 反应；O–H 键和相连 C 上的 C–H 键同时断开 → 催化氧化成乙醛。和水相比，乙醇羟基上的 H 更“懒”，所以与钠反应更温和。
✏️ 例题　把一根光亮的铜丝在酒精灯上加热，表面变黑，趁热插入乙醇中，又变成光亮的红色。重复几次，闻到刺激性气味。写出相关反应并说明铜的作用。
点我看解析

2Cu + O2 =△= 2CuO；CuO + CH3CH2OH → Cu + CH3CHO + H2O；总反应 2CH3CH2OH + O2 →（Cu，△）2CH3CHO + 2H2O，铜是催化剂。

⚠️ 易错提醒：1 mol 乙醇与足量钠反应只生成 0.5 mol H2：只有羟基上的 H 能被置换。

🔬 乙酸与酯化反应实验

  • 乙酸（醋酸）：有强烈刺激性气味，16.6 ℃ 以下凝结成冰状（冰醋酸）；官能团羧基 —COOH；酸性比碳酸强
2CH3COOH + CaCO3(CH3COO)2Ca + H2O + CO2↑醋除水垢
2CH3COOH + CaCO3Ca2+ + 2CH3COO- + H2O + CO2↑

酯化反应：酸与醇反应生成酯和水（属于取代反应，可逆）。机理：酸脱羟基，醇脱氢

CH3COOH + CH3CH2OH浓硫酸⇌△CH3COOCH2CH3 + H2O
细节作用
浓硫酸催化剂、吸水剂（使平衡向生成酯的方向移动）
饱和 Na2CO3 溶液① 中和乙酸 ② 溶解乙醇 ③ 降低乙酸乙酯的溶解度，便于分层
导管不伸入液面以下防止倒吸
碎瓷片防止暴沸
分离产物分液（乙酸乙酯在上层）
💡 老师讲透：酯化反应的“断键位置”：酸脱羟基（—OH），醇脱氢（—H）。用 ¹⁸O 标记乙醇做实验，¹⁸O 出现在乙酸乙酯中而不在水中，这就是证据。它是可逆反应，所以要用浓硫酸吸水、及时蒸出产物来提高产率。
✏️ 例题　用 CH3CH218OH 与乙酸发生酯化反应，¹⁸O 存在于哪些物质中？
点我看解析

¹⁸O 存在于乙酸乙酯（CH3CO18OCH2CH3）和未反应的乙醇中，生成的水中没有 ¹⁸O。

⚠️ 易错提醒：收集乙酸乙酯不能用 NaOH 溶液，会使乙酸乙酯水解。

📋 官能团：有机物的“技能卡”

官能团名称代表物典型反应
C=C碳碳双键乙烯加成、加聚、使酸性 KMnO₄ 褪色
—X碳卤键（卤素原子）CH3Cl、CH2BrCH2Br—
—OH羟基乙醇与 Na 反应、催化氧化、酯化
—CHO醛基乙醛、葡萄糖被新制 Cu(OH)2 氧化（砖红色沉淀）
—COOH羧基乙酸酸性、酯化

比较羟基氢的活泼性：乙酸 > 水 > 乙醇（乙酸能与 NaHCO3 反应放出 CO2，乙醇不能）。

💡 老师讲透：官能团就是有机物的“技能卡”：看到 C=C 想加成、加聚、使 KMnO₄ 褪色；看到 —OH 想 Na、催化氧化、酯化；看到 —COOH 想酸性和酯化。一个分子有几个官能团，就同时拥有几张技能卡。
✏️ 例题　某有机物结构简式为 CH2=CH-COOH（丙烯酸），它能发生哪些反应？1 mol 它最多与多少 mol Br2、多少 mol Na 反应？
点我看解析

含 C=C：加成、加聚、使酸性 KMnO₄ 褪色；含 —COOH：酸性、酯化。1 mol 最多与 1 mol Br2 加成，与 1 mol Na 反应。

📌 油脂与蛋白质

油脂：高级脂肪酸与甘油形成的酯。植物油（液态，含较多碳碳双键，能使溴水褪色，可“氢化”成硬化油）；动物脂肪（固态）

  • 酸性条件下水解 → 高级脂肪酸 + 甘油
  • 碱性条件下水解 → 高级脂肪酸盐（肥皂）+ 甘油，叫皂化反应

蛋白质：由氨基酸构成的天然高分子

  • 水解：最终产物是氨基酸
  • 变性（不可逆）：加热、紫外线、重金属盐（CuSO4、铅盐）、强酸强碱、乙醇、甲醛 → 高温消毒、误服重金属盐可喝牛奶解毒
  • 显色反应：含苯环的蛋白质遇浓硝酸变黄
  • 灼烧有烧焦羽毛气味 → 鉴别蚕丝、羊毛与棉花、化纤

⚠️ 油脂不是高分子；淀粉、纤维素、蛋白质是天然高分子。

💡 老师讲透：油脂和蛋白质对比记：油脂水解是“断酯基”，碱性水解叫皂化；蛋白质水解得到氨基酸。蛋白质的“盐析”可逆（用于提纯），“变性”不可逆（用于消毒）。
✏️ 例题　下列做法利用了蛋白质变性的是：①用酒精消毒 ②用饱和 (NH4)2SO4 溶液提纯蛋白质 ③高温蒸煮餐具 ④误服 CuSO4 后喝大量牛奶
点我看解析

①③④。② 是盐析（可逆）；④ 让牛奶中的蛋白质代替人体蛋白质与重金属盐结合。

⚠️ 易错提醒：“油脂、淀粉、蛋白质都是高分子”是错的，油脂不是高分子。

⚠️ 本章易错点

  • ✗ 用酸性 KMnO₄ 溶液除去甲烷中的乙烯✓ 乙烯被氧化成 CO₂，引入新杂质；应通过溴水
  • ✗ CH₄ 与 Cl₂ 1:1 光照只生成 CH₃Cl✓ 四种氯代物和 HCl 同时生成
  • ✗ 乙烯结构简式写成 CH₂CH₂✓ 碳碳双键不能省：CH₂=CH₂
  • ✗ 淀粉与纤维素互为同分异构体✓ (C₆H₁₀O₅)ₙ 中 n 不同，分子式不同
  • ✗ 酯化反应中醇脱羟基、酸脱氢✓ 酸脱羟基、醇脱氢（同位素示踪 ¹⁸O 证明）

🏠 化学品的合理使用

  • 🌾 化肥：合理施用；铵态氮肥不能与草木灰（碱性）混用
  • 🐛 农药：向高效、低毒、低残留方向发展
  • 💊 合理用药：处方药（R）需凭医生处方，非处方药（OTC）可自行购买；阿司匹林是常用解热镇痛药；“是药三分毒”，杜绝滥用抗生素
  • 🍬 食品添加剂：着色剂、增味剂（味精）、膨松剂（NaHCO3）、凝固剂、防腐剂（苯甲酸钠、山梨酸钾）、抗氧化剂（维生素 C）、营养强化剂（加碘盐中的 KIO3）；必须按国家标准限量使用
  • ⚠️ 亚硝酸钠可作防腐剂和护色剂，但有毒，严格限量；三聚氰胺、苏丹红等不是食品添加剂
💡 老师讲透：化学品没有“好坏”，关键在“量”和“用法”。合理使用的三原则：按标准、按需要、按规范。看到“纯天然、零添加”的广告，要用化学知识理性判断。

📌 绿色化学与原子经济性

  • 绿色化学（环境友好化学）：从源头上减少或消除环境污染，而不是“先污染后治理”
  • 原子经济性：反应物的原子全部转化为期望的最终产物，原子利用率 100%

原子利用率 = 期望产物的总质量 ÷ 全部反应物的总质量 × 100%

例：用乙烯制环氧乙烷（C2H4O）

2C2H4 + O2Ag⟶2C2H4O(环氧乙烷)

只有一种产物 → 原子利用率 100%。化合反应、加成反应、加聚反应都是原子经济性好的反应。

环境保护三大问题：大气污染（酸雨、光化学烟雾、雾霾、臭氧层破坏）、水污染（赤潮、水华——N、P 过多）、土壤污染与白色污染。

💡 老师讲透：绿色化学是“预防”，不是“治理”。判断原子经济性最快的方法：只生成一种产物的反应（化合、加成、加聚）原子利用率是 100%。
✏️ 例题　以下制取 CuSO4 的方案，哪种最符合绿色化学？① Cu + 浓 H2SO4 加热　② 先把 Cu 在空气中加热成 CuO，再与稀 H2SO4 反应
点我看解析

方案②：2Cu + O2 =△= 2CuO，CuO + H2SO4 = CuSO4 + H2O，不产生污染性的 SO2，且消耗的硫酸只有方案①的一半。

⚠️ 易错提醒：“先污染后治理”（如末端处理尾气）不属于绿色化学的核心思想。

🧠 易错与解题模型

硫氮转化链 · 原电池判断 · 平衡标志判断 · 有机反应类型

👩‍🏫
高一下的考题最爱在四个地方“挖坑”：硫氮转化里的特殊现象、原电池里的反常负极、平衡标志里的假变量、有机反应里的类型混淆。下面每个模型都是一张检查清单——做题前先在草稿纸上走一遍。

🧱 前置地基：先确认这些会了

  • 氧化还原配平得失电子守恒（硫氮转化、电极反应式）高一上·配平模型 ↗
  • 双线桥电子转移方向与数目高一上·双线桥 ↗
  • 离子共存H⁺ + NO₃⁻ 有强氧化性，与 Fe²⁺、SO₃²⁻ 不共存高一上·离子共存 ↗

点 ↗ 在新标签页打开《高一上》或《初中》导图的对应小节；不熟就先回补，再往下看。

📌 模型① 硫氮转化链：两条主线 + 一张陷阱表

🟡 硫线S → SO₂ → SO₃ → H₂SO₄🔵 氮线N₂ → NO → NO₂ → HNO₃🧪 氨线N₂ → NH₃ → NO（工业制硝酸）📏 价态律最高价只有氧化性，最低价只有还原性，中间价两者都有
常考陷阱正确结论
S 在过量 O2 中燃烧生成 SO3只生成 SO2，SO2 → SO3 要催化剂、加热
N2 与过量 O2 一步生成 NO2只生成 NO
SO2 与 Cl2 按 1:1 通入品红，漂白更强恰好反应生成 H2SO4 和 HCl，失去漂白性
足量 Cu 与浓硫酸（或浓硝酸）完全反应浓硫酸变稀后停止；浓硝酸变稀后生成 NO（气体是 NO2 和 NO 的混合物）
Fe(NO3)2 溶液中加稀硫酸无变化H+ + NO3- 把 Fe2+ 氧化为 Fe3+，溶液变黄

鉴别 SO2 和 CO2：用品红溶液（褪色的是 SO2）或酸性 KMnO₄ 溶液/溴水；不能用澄清石灰水（都变浑浊）。

📌 模型② 原电池判断：四步清单

  1. 找总反应：哪个电极材料能和电解质溶液自发反应？
  2. 定负极：失电子的那一极是负极（不一定是更活泼的）
  3. 画流向：电子 负→导线→正；阳离子 → 正极，阴离子 → 负极
  4. 写电极：负极失电子、正极得电子，两式相加 = 总反应，并结合电解质环境
装置负极原因
Mg–Al–稀硫酸MgMg 更活泼
Mg–Al–NaOH 溶液Al只有 Al 与 NaOH 溶液反应
Fe–Cu–浓硝酸（常温）CuFe 钝化，Cu 与浓硝酸反应
Zn–Cu–CuSO4 溶液Zn正极析出红色的 Cu，正极质量增加
2Al + 8OH- − 6e-2[Al(OH)4]-Mg–Al–NaOH 负极
6H2O + 6e-3H2↑ + 6OH-正极

📌 模型③ 平衡标志判断：“变量不变”

例：恒温恒容下，N2 + 3H2 ⇌ 2NH3，下列能说明达到平衡的是：

说法判断理由
单位时间内生成 n mol N2，同时消耗 3n mol H2✓一逆一正，且符合 1:3
单位时间内消耗 n mol N2，同时生成 2n mol NH3✗都是正反应方向
容器内总压强不再变化✓反应前后气体分子数不同，压强是变量
混合气体的密度不再变化✗气体总质量、体积都不变，密度始终不变
混合气体的平均相对分子质量不变✓质量不变、总物质的量在变
c(N2) : c(H2) : c(NH3) = 1:3:2✗比例特定不代表浓度不再变化
NH3 的浓度不再变化✓直接标志

换成 H2 + I2(g) ⇌ 2HI：压强不变 ✗（气体分子数不变，压强始终不变）；颜色不变 ✓（I2 浓度不变）。

📋 模型④ 有机反应类型：一眼认出

类型特点典型例子
取代有上有下（像“换人”）CH4 与 Cl2 光照；酯化反应；酯、油脂的水解
加成只上不下，双键变单键乙烯与 Br2、H2、HCl、H2O
加聚小分子手拉手连成高分子乙烯 → 聚乙烯
氧化得氧或去氢燃烧；乙醇催化氧化；乙烯、乙醇使酸性 KMnO₄ 褪色
酯化酸脱羟基醇脱氢（属于取代）乙酸 + 乙醇
水解与水作用分解（属于取代）蔗糖、淀粉、油脂、蛋白质的水解
  • ✗ 乙烯使溴水褪色和使酸性 KMnO₄ 褪色原理相同✓ 前者是加成反应，后者是氧化反应
  • ✗ 苯（或己烷）使溴水层褪色是加成反应✓ 是萃取（物理变化）
  • ✗ 除去乙酸乙酯中的乙酸用 NaOH 溶液✓ NaOH 会使酯水解；用饱和 Na₂CO₃ 溶液后分液
